밀플랜 가이드북

템플릿 사용 가이드 · 비개발자 워킹맘이 직접 만들고 매일 쓰는 식단 관리 · 온트 ONT

코딩 몰라도 괜찮아요. 제가 만든 템플릿을 복사해서 바로 쓰시면 돼요.
제가 모은 레시피도 이미 들어 있어요.

이게 뭐예요?

"뭐 먹지?" "장은 뭐 사야 하지?" 매번 고민되시죠. 인스타에서 저장한 레시피는 많은데 다시 찾기도 어렵고요.

이 템플릿은 그 고민을 대신 해주는 우리 집 식단 관리표예요.

🔗 인스타 레시피 링크 넣기→✅ 먹고 싶은 메뉴 체크→🛒 식단 · 장보기 리스트 자동 완성

냉장고에 있는 재료까지 반영해서 일주일 식단을 짜고, 없는 재료만 장보기 리스트에 채워줘요.

준비물

📋
클로드 계정, 구글 계정, 클로드 API 키, Apify 토큰 4가지를 준비하세요. 없다면 아래를 펼쳐서 차례대로 만들어 주세요.
1️⃣ 클로드 시작하기

1단계. 사이트 들어가서 가입하기

  • 주소창에 claude.ai 입력 → 접속
  • "Sign up" 버튼 클릭 → 구글 계정으로 가입 (제일 빠르고 쉬워요!)

2단계. 채팅창에 질문하기

  • 가입 후 나오는 하얀 채팅창에 궁금한 걸 물어보면 끝!
  • 예시: "초등학생도 이해하게 화산이 왜 폭발하는지 설명해줘"

템플릿을 쓰다 막히거나 우리 집에 맞게 바꾸고 싶을 때 클로드에게 물어보면 돼요.

2️⃣ 구글 계정 만들기
  • sheets.google.com 접속 → "계정 만들기" 클릭
  • 이름·생년월일·Gmail 주소·비밀번호 설정 (약 5분)
  • 한 번 만들면 지메일, 문서, 드라이브까지 같은 계정으로 써요
3️⃣ 클로드 API 키 발급받기

API 키는 템플릿이 레시피를 정리하고 식단을 짤 때 클로드를 부르는 나만의 비밀 열쇠예요.

  1. console.anthropic.com 접속 → 가입 (클로드 계정과 같은 이메일로 해도 돼요)
  2. 왼쪽 메뉴 Billing(결제)에서 크레딧을 소액 충전해요
  3. 왼쪽 메뉴 API Keys → Create Key → 이름은 "밀플랜" 정도로
  4. 나온 키(sk-ant-로 시작)를 바로 복사해서 메모장에 저장해요. 창을 닫으면 다시 볼 수 없어요
⚠️
클로드 앱 구독과 API는 결제가 따로예요. 구독 중이어도 API 크레딧은 별도로 충전해야 해요. 쓴 만큼만 차감돼요.
API 키는 절대 다른 사람에게 보여주지 마세요. 내 크레딧이 쓰일 수 있어요. 노출됐다면 콘솔에서 바로 삭제하고 새로 만드세요.
4️⃣ Apify 토큰 발급받기

Apify는 템플릿이 인스타 게시물의 캡션(레시피 글)을 읽어올 때 쓰는 도구예요. 인스타는 로그인 없이 내용을 잘 안 보여줘서, 이 도구가 대신 읽어와요.

  1. apify.com 접속 → Sign up (구글 계정으로 가입하면 빨라요)
  2. 로그인 후 오른쪽 위 Settings → Integrations (또는 API & Integrations)
  3. API token 옆 복사 버튼을 눌러 메모장에 저장해요
⚠️
Apify는 매달 무료로 쓸 수 있는 한도가 있고, 넘으면 비용이 생겨요. 한도는 Apify 요금 페이지에서 확인하세요.
토큰도 API 키처럼 절대 다른 사람에게 보여주지 마세요.

1단계 · 템플릿 내 것으로 복사하기

📋 밀플랜 템플릿 사본 만들기
  1. 위 버튼을 누르면 "문서 사본을 만드시겠습니까?" 화면이 열려요
  2. 사본 만들기를 누르면 내 구글 드라이브에 저장돼요
  3. 이름은 마음대로 바꿔도 괜찮아요 (탭 이름만 바꾸지 마세요)
💡
꼭 사본에서 작업하세요. 사본은 온전히 내 것이라 마음껏 써도 다른 사람에게 보이지 않아요.

2단계 · 처음 한 번만 하는 설정

① 키 2개 넣기

  1. 사본 위쪽 메뉴에서 확장 프로그램 → Apps Script를 눌러요
  2. 왼쪽 톱니바퀴 프로젝트 설정 → 맨 아래 스크립트 속성 추가
  3. 속성 CLAUDE_API_KEY / 값: 클로드 API 키 → 한 줄 더 추가해서 속성 APIFY_API_TOKEN / 값: Apify 토큰 → 저장
💡
속성 이름은 대문자·밑줄까지 똑같이 적어야 해요. 위 글자를 그대로 복사해서 붙여넣으세요.

② 메뉴 열고 권한 허용하기

  1. 시트로 돌아와 새로고침하면 위쪽에 🍽 식단 자동화 메뉴가 생겨요 (몇 초 걸릴 수 있어요)
  2. 메뉴에서 아무 기능이나 처음 누르면 "승인 필요" 창이 떠요 → 계속 → 내 계정 선택
  3. "Google에서 확인하지 않은 앱" 화면이 나오면 고급 → 밀플랜(으)로 이동(안전하지 않음) → 허용
🙋‍♀️
무섭게 생긴 경고지만, 내가 복사한 내 시트가 내 계정에서 돌아가도 되냐고 묻는 거예요. 처음 한 번만 나와요.

③ 매주 자동으로 식단 받기 (선택)

🍽 식단 자동화 → 자동 실행 스케줄 재설정을 누르면 매주 토요일 0시(금요일 밤 자정)에 다음 주 식단이 자동으로 만들어져요.

3단계 · 냉장고 재료 적기

냉장고재료 탭에 지금 집에 있는 재료를 적어요. 이걸 보고 이미 있는 재료는 장보기에서 빼줘요.

4단계 · 인스타 레시피 링크 넣기

  1. 인스타에서 저장해둔 요리 릴스의 링크를 복사해요 (게시물 ··· → 링크 복사)
  2. 🍽 식단 자동화 → 링크로 레시피 추가하기를 누르고 링크를 붙여넣어요
  3. 메뉴명·재료·조리법이 레퍼런스레시피 탭에 자동으로 정리돼요

5단계 · 이번 주 메뉴 고르기

  1. 레퍼런스레시피 탭에서 먹고 싶은 메뉴의 이번주픽 칸에 먹을 횟수(1 또는 2)를 적어요
  2. 🍽 식단 자동화 → 지금 식단 생성하기를 누르면 주간식단추천 탭에 일주일 식단이 나와요
  3. 마음에 들면 추천 확정하기를 눌러요. 주간식단 탭으로 옮겨져요

6단계 · 장보기 리스트 확인

🍽 식단 자동화 → 장보기 리스트 생성하기를 누르면 장보기리스트 탭에 냉장고에 없는 재료만 정리돼요. 마트 가기 전에 이 탭만 열면 끝!

일요일에 한 번에 조리해두고 싶다면 밀프렙 가이드 만들기를 눌러보세요. 일요일밑작업 탭에 배치 조리 방법이 정리돼요.

7단계 · 폰에서 앱처럼 쓰기 (선택)

  1. 확장 프로그램 → Apps Script → 오른쪽 위 파란 배포 → 새 배포
  2. 유형 선택 톱니바퀴에서 웹 앱 → 실행: 나, 액세스 권한: 나만 → 배포
  3. 시트로 돌아와 🍽 식단 자동화 → 📱 모바일 앱 링크 만들기
  4. 레퍼런스레시피 탭 맨 위(B1)에 내 앱 링크가 생겨요. 폰에서 열고 홈 화면에 추가하면 앱처럼 쓸 수 있어요
📱
폰에서도 시트를 만든 같은 구글 계정으로 로그인되어 있어야 열려요.

우리 집에 맞게 바꾸고 싶으면

  • 주간설정 탭: 주차별 예산, 밀프렙 베이스 재료, 인분 수, 단백질 우선 여부를 적을 수 있어요
  • 기본으로 목요일 점심은 배달, 토·일 점심은 외식으로 잡혀 있어요 (만든 사람 우리 집 패턴이에요). 모바일 앱에서는 끼니마다 집밥·외식·배달을 눌러서 바꿀 수 있어요
  • 같은 메뉴는 이번주픽에 적은 횟수(최대 2번)까지만 나와요
